# STOCK_PRICE_PRDICTION_MODEL
Instructions to Run the Project
1. Clone the repository.

2. Review StockReport.pdf for complete details on the libraries and technologies used.

3. Run the Jupyter notebook (.ipynb) to generate the .keras trained model for prediction.

4. Update app.py with the path to the generated .keras model.

5. Launch the application by running app.py.

6. If you encounter any issues, try running the following command from the terminal: " streamlit run app.py "
